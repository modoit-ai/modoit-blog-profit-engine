# 리서치·SEO·성장

## 1. 수익성 있는 주제 발굴

관심사와 경험을 단순 인기 주제가 아니라 `독자 문제 × 검색 수요 × 경쟁 공백 × 수익 연결 × 지속 가능성`의 교집합으로 좁힌다.

### 후보 발굴

1. 사용자가 직접 설명하거나 경험을 보탤 수 있는 영역을 모은다.
2. 각 영역에서 구체적인 독자와 상황을 붙여 롱테일 후보를 만든다. 예: `요리`보다 `맞벌이 2인 가구 15분 냉동식단`.
3. 검색 결과와 키워드 자료를 확인해 수요, 경쟁 강도, 최신성, 상위 문서의 약점을 조사한다.
4. 광고 단가 하나만 보지 말고 제휴 상품, 서비스, 협찬, 자체 상품으로 이어지는지 확인한다.
5. 최소 20~30개의 글 아이디어로 확장 가능한지 점검한다.

### 비교 기준

각 후보를 1~5점으로 평가하고 근거를 한 문장씩 붙인다.

- 경험 적합도: 사용자의 실제 경험과 전문성을 얼마나 활용할 수 있는가
- 수요 신호: 검색·커뮤니티 질문·반복 문제의 신호가 있는가
- 경쟁 기회: 상위 결과가 낡았거나 얕거나 특정 독자를 놓치고 있는가
- 수익 연결성: 독자 문제 해결 과정에 자연스러운 유료 선택지가 있는가
- 제작 지속성: 주어진 시간으로 꾸준히 취재·작성할 수 있는가
- 리스크: YMYL, 법률·의료·금융 정확성, 계절성, 플랫폼 의존도가 과도하지 않은가

3개를 추천하고 예상 수익 모델, 초기 글 묶음, 차별화 각도를 함께 제시한다. 초보자용 1순위는 총점만으로 고르지 말고 빠른 제작, 검증 주기, 신뢰 확보 난이도를 함께 설명한다.

## 2. SEO 점검

### 검색 의도와 페이지 적합성

- 핵심 키워드의 실제 검색 결과를 보고 사용자가 원하는 형식이 가이드, 목록, 비교, 후기, 도구 중 무엇인지 확인한다.
- 제목·도입부·소제목·본문·이미지 설명·결론이 같은 의도를 지원하는지 본다.
- 관련 키워드는 자연스럽게 포함하되 정해진 밀도나 반복 횟수를 목표로 삼지 않는다.

### 경쟁 문서 비교

상위 문서 3~5개를 가능하면 같은 플랫폼과 같은 검색 의도로 비교한다. 다음을 증거와 함께 기록한다.

- 다루는 하위 질문과 빠진 질문
- 정보의 최신성, 구체성, 원본 경험과 근거
- 구조, 읽기 편의성, 표·이미지·예시의 역할
- 내부링크와 다음 행동
- 글 길이는 맥락으로만 보고 목표 글자 수를 맹목적으로 복제하지 않는다.

경쟁 글의 문장을 베끼지 않는다. 사용자가 더 명확하고 유용하게 답할 수 있는 정보 공백을 찾는다.

### 감사 결과

문제를 `치명적 / 높은 영향 / 개선 권장`으로 구분하고 각 항목에 아래를 붙인다.

- 문제와 증거
- 검색·독자 경험에 미치는 영향
- 수정 예시
- 기대 지표

제목 3개, 개선된 소제목 구조, 내부링크 후보, 이미지 또는 도표 제안, 메타 설명이 유효한 플랫폼이면 메타 설명까지 제공한다.

## 3. 발행과 성장 로드맵

목표를 계산할 때 방문자와 페이지뷰를 구분한다. 광고 중심의 기본식은 다음과 같다.

`예상 광고 수익 = 월 페이지뷰 ÷ 1,000 × 페이지 RPM`

제휴·상품 중심의 기본식은 다음과 같다.

`예상 수익 = 관련 페이지 방문 수 × CTA 클릭률 × 전환율 × 건당 수익`

RPM, 클릭률, 전환율을 모르면 확정값을 만들지 말고 범위를 사용한다. 실제 30일 데이터를 확보한 뒤 다시 계산하도록 한다.

### 단계별 계획

- 0~2개월: 주제와 검색 의도 검증, 핵심 콘텐츠 묶음, 측정 환경 구축
- 3~4개월: 성과 글 업데이트, 내부링크, 첫 수익 채널 실험
- 5~6개월: 전환 최적화, 이메일 또는 재방문 채널, 협찬용 자료 준비
- 7~12개월: 검증된 하위 주제 확장, 자체 상품·서비스, 플랫폼 리스크 분산

기간은 고정 규칙이 아니다. 현재 글 수, 색인 속도, 플랫폼, 가용 시간에 따라 조정한다. 각 단계에 월별 산출물, 선행 지표, 중단·확대 기준을 붙인다.

### 정체기 체크리스트

- 노출이 줄었는가, 노출은 같은데 클릭률이 줄었는가
- 순위는 유지되지만 검색 수요가 계절적으로 줄었는가
- 상위 유입 글이 오래되어 정보가 낡았는가
- 새 글이 기존 글과 키워드를 서로 잠식하는가
- 유입은 있는데 CTA 클릭 또는 전환이 낮은가
- 특정 플랫폼이나 한 개 글에 트래픽이 과도하게 집중되어 있는가
- 발행량보다 품질·업데이트·내부링크가 병목인가

정체기에는 무조건 새 글 수를 늘리지 말고 병목 지표에 맞는 한 가지 실험을 2~4주 단위로 설계한다.
